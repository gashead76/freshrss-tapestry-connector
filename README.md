# freshrss-tapestry-connector
This is a connector for Iconfactory's app Tapestry that connects to a FreshRSS instance. Its got some personal tricks to it that may not be useful to other folks however.

There are plenty of random things that don't work right yet, no icon for the connector exists yet, plus its kind of a set-and-forget type of thing. it'll just mark everything it pulls as read, which means any other app you may use will show all articles as read.
